PHP, plus connu sous son sigle PHP (sigle auto-référentiel), est un langage de programmation libre, créé en 1994 par Rasmus Lerdorf et dont la première version a été publiée le 8 juin 1995, principalement utilisé pour produire des pages Web dynamiques via un serveur web, mais pouvant également fonctionner comme n'importe quel langage interprété de façon locale. PHP est un langage impératif orienté objet.

  • PHP est principalement utilisé pour le développement web
  • PHP permet de créer des pages web dynamiques
  • PHP a permis de créer Facebook et Wikipédia entre autres
